Add Student
Create a student account record. Role defaults to student.
Password handling & President Role
Passwords are set as the student ID by default. Users are encouraged to change their passwords upon first login. Promote students to President using the More menu (⋮) in the Active tab.
Add President
Create a president account record. Role will be set to org_president.
Password handling
Passwords are set as the ID Number by default. Users are encouraged to change their passwords upon first login.

Password handling

Add Moderator
Create a moderator account record.

Password handling

CSV Import
Upload a CSV file to import records.
CSV format reminder
Use headers. Suggested columns: id_number, first_name, middle_name, last_name, suffix, email, program, year_level, school_year, role, status.
Year Level options: 1st Year, 2nd Year, 3rd Year, 4th Year, 5th Year, Irregular
Role options: student, org_president (for importing presidents)
Tip: If importing staff, roles must be faculty_admin or moderator. For presidents, use role org_president.
